# Contributing

Open an issue before major changes. Keep production JavaScript dependency-free, use native browser APIs, and preserve compatibility with existing profile JSON. Run `node --test tests/*.test.js`, `bash -n` on shell scripts, and `./scripts/package.sh` before proposing a change. Do not include real IP addresses, secrets or proxy credentials in screenshots or bug reports. Submit a pull request against `main` with a concise description and test evidence.
