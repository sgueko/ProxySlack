ProxySlack · Guide

Installation

  1. Extract the archive.
  2. Open chrome://extensions in Chromium or Chrome (edge://extensions in Edge).
  3. Enable Developer mode, choose “Load unpacked”, and select the ProxySlack folder.
  4. Pin ProxySlack to the toolbar.

Profiles

ProxySlack initially leaves the browser proxy setting alone. Select a profile to activate it. The “Apply for all protocols” checkbox is on by default. It applies the same proxy to HTTP, HTTPS, FTP, and the fallback category of Chromium requests. If you turn it off, select one destination protocol; the other protocols connect directly. The profile type describes the connection to the proxy server.

The Tor HTTP profile uses 127.0.0.1:8118 and needs an HTTP-to-Tor relay such as Privoxy. The Tor SOCKS5 profile uses 127.0.0.1:9050 and needs a running Tor SOCKS service. ProxySlack does not start these services.

Settings

The ⚙ button lets you choose the interface language (browser, English, or French) and an HTTPS URL for the IP test. The service must return only an IP address as plain text or JSON containing only an ip field. HTML pages, redirects, and large responses are rejected. A custom site needs permission when saved.

IP test and JSON

“Test my IP” contacts api.ipify.org only on request. Export saves profiles as JSON. Import replaces them and returns to browser settings. Older JSON files default to applying all protocols.

Privacy limits

A Chromium proxy is not a VPN or an anonymity guarantee. It does not change your operating system's proxy settings or protect other applications. Some browser or system mechanisms may use other network paths. For sensitive use, choose Tor Browser.

Profiles stay in local storage. ProxySlack has no page scripts, browsing-history access, or telemetry. An IP test does not prove that all traffic uses a proxy.
