ProxySlack · Guide

Installation

  1. Décompressez l’archive.
  2. Dans Chromium ou Chrome, ouvrez chrome://extensions (dans Edge, edge://extensions).
  3. Activez le mode développeur, choisissez « Charger l’extension non empaquetée » puis le dossier ProxySlack.
  4. Épinglez ProxySlack à la barre d’outils.

Premiers pas

Au démarrage, ProxySlack laisse le réglage du navigateur en place. Choisissez un profil pour l’activer. La case « Appliquer à tous les protocoles » est cochée par défaut : le même proxy s’applique aux destinations HTTP, HTTPS, FTP et à la règle de repli de Chromium. Si elle est décochée, choisissez un seul protocole de destination ; les autres utilisent une connexion directe. Le protocole du profil décrit la connexion au proxy. L’extension ne modifie pas les réglages proxy du système d’exploitation.

« Mode direct » désactive explicitement l’usage d’un proxy par Chromium. « Réglage navigateur » libère le contrôle de l’extension.

Les profils Tor fournis utilisent 127.0.0.1:8118 en HTTP et 127.0.0.1:9050 en SOCKS5. Le premier nécessite un relais HTTP tel que Privoxy ; le second nécessite un service Tor SOCKS5. L’extension ne démarre pas ces services.

Paramètres

Le bouton ⚙ permet de choisir la langue de l’interface (navigateur, anglais ou français) et une URL HTTPS pour le test IP. Le service doit renvoyer seulement une adresse IP en texte brut ou un JSON contenant uniquement le champ ip. Les pages HTML, redirections et réponses volumineuses sont refusées. Un site personnalisé nécessite une permission accordée à l’enregistrement.

Badge et test IP

ON signifie qu’un profil est sélectionné, DIR que le mode direct est sélectionné, et ! qu’une autre règle contrôle le proxy. « Tester mon IP » contacte api.ipify.org à votre demande et affiche l’IP publique qu’il observe.

Import et export

L’export télécharge les profils en JSON. L’import remplace tous les profils et revient au réglage navigateur. Le fichier peut contenir jusqu’à 100 profils et doit peser moins de 100 Ko. Il contient les adresses des proxys en clair.

Limites de confidentialité

Un proxy Chromium n’est pas un VPN ni une garantie d’anonymat. Le test IP ne vérifie qu’une requête vers un service. D’autres applications et certains mécanismes du navigateur ou du système (par exemple WebRTC ou DNS selon la configuration) peuvent utiliser d’autres chemins. Pour des usages sensibles, utilisez Tor Browser.

Les profils sont stockés localement ; ProxySlack ne collecte pas d’historique, n’injecte pas de script dans les pages et n’envoie pas de télémétrie. Le test IP est la seule requête vers un service externe déclenchée par l’extension.
